# MajesticLogBridge

Плагин для [Vencord](https://vencord.dev/), который связывает Discord с приложением **Majestic Log Analyzer**: находит в сообщениях вложения с логами (`.log`, `.txt`) и открывает их в анализаторе одним кликом.

---

## Возможности

- 🔍 **Автопоиск логов** во вложениях сообщения (включая ответы и снапшоты пересланных сообщений).
- 📂 **Пункт контекстного меню** «Открыть логи в Majestic Log Analyzer».
- 🔘 **Встроенная кнопка** под сообщением с лог-вложениями (можно отключить в настройках).
- 🚀 **Автозапуск анализатора**, если он ещё не открыт.
- 🧠 **Умная передача через именованный канал (named pipe)** — без открытия новых окон анализатора на каждый файл.
- 🧹 **Автоочистка** временных файлов старше 7 дней.
- 🛡️ **Проверки безопасности**: скачиваются только URL с доменов Discord, с ограничениями по размеру и количеству файлов.

---

## Требования

| Компонент | Версия / примечание |
|---|---|
| ОС | **Windows** (используется именованный канал Windows и `.exe`) |
| Discord | клиент с установленным [Vencord](https://vencord.dev/) |
| [Majestic Log Analyzer]([https://github.com/](https://github.com/pups284/MJ-and-RO-logs-analyzer)) | установленный `.exe` |

> ⚠️ Плагин работает **только на Windows** и **только вместе с приложением Majestic Log Analyzer**.

## Установка

### 1. Установите [Majestic Log Analyzer](https://github.com/pups284/MJ-and-RO-logs-analyzer/releases/latest)

Приложение должно быть установлено в одном из стандартных мест:

- `%LOCALAPPDATA%\Programs\Majestic Log Analyzer\MajesticLogAnalyzer.exe`
- `C:\Program Files\Majestic Log Analyzer\MajesticLogAnalyzer.exe`
- `C:\Program Files (x86)\Majestic Log Analyzer\MajesticLogAnalyzer.exe`

Если оно установлено в другое место — просто укажите путь в настройках плагина (см. ниже) или задайте переменную окружения `MAJESTIC_LOG_ANALYZER_PATH`.

### 2. Установите плагин в Vencord

Скопируйте папку плагина в директорию пользовательских плагинов Vencord ***(Vencord должен быть установлен через терминал)***:

```
<Vencord>\src\userplugins\MajesticLogBridge\
├── index.tsx
└── native.ts
```

После пересборки Vencord (`pnpm build`) плагин появится в списке и будет **включён по умолчанию**.

---

## Настройки плагина

Откройте **Настройки → Vencord → Плагины → MajesticLogBridge**:

| Опция | Тип | По умолчанию | Описание |
|---|---|---|---|
| `autoOpen` | boolean | `true` | Открывать первый полученный лог в анализаторе |
| `showInlineButton` | boolean | `true` | Показывать кнопку под сообщением с логами |
| `appPath` | string | `""` | Свой путь к `MajesticLogAnalyzer.exe` (пусто — автопоиск) |

---

## Использование

1. Отправьте (или получите) сообщение с вложением `.log` или `.txt`.
2. Под сообщением появится кнопка **«Открыть логи в Majestic Log Analyzer»**.
   Либо откройте контекстное меню сообщения (ПКМ) → **«Открыть логи в Majestic Log Analyzer (N)»**.
3. Плагин:
   - скачает вложения во временную папку,
   - передаст их в анализатор через named pipe `\\.\pipe\MajesticLogAnalyzer_SingleInstance`,
   - при необходимости запустит приложение и повторит попытку.

## Ограничения и безопасность

| Параметр | Значение |
|---|---|
| Максимум файлов за раз | **32** |
| Максимум на один файл | **64 МБ** |
| Максимум суммарно | **256 МБ** |
| Разрешённые домены | `*.discordapp.com`, `*.discordapp.net`, `*.discord.com` |
| Срок жизни временных файлов | 7 дней (автоочистка при следующем запуске) |

- Скачиваются **только** вложения с доверенных CDN-доменов Discord.
- Имена файлов санитизируются (`basename`, замена запрещённых символов).
- Плагин не выполняет никакого кода из скачанных файлов — только передаёт путь анализатору.

## Устранение неполадок

| Проблема | Решение |
|---|---|
| «Majestic Log Analyzer is not installed» | Укажите путь к `.exe` в настройке `appPath` или задайте `MAJESTIC_LOG_ANALYZER_PATH` |
| «Timed out while contacting Majestic Log Analyzer» | Убедитесь, что анализатор запущен или может быть запущен (проверьте права) |
| «Could not download logs (HTTP 403/404)» | Вложение удалено или недоступно — попробуйте другое сообщение |
| «file is too large» | Вложение превышает 64 МБ — ограничение плагина |
| Кнопка/пункт меню не появляются | Убедитесь, что вложение имеет расширение `.log` или `.txt` |
